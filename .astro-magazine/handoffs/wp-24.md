# WP-24 handoff: hubs and tools media density (issue #90, wave 11)

## What changed

Every hub now opens with at least two media moments (a diagram, sourced chart, scene, illustration or row of sourced figures) in the
first viewport or the section right after it, followed by an early interaction and a next action. Every tool page draws what it computes
above the tool. All media is authored SVG or HTML drawn at build time, and no new JavaScript ships: the filters are CSS alone
(`:has(:checked)`), and the industries orbit is static.

- **Hub media kit, `src/components/hubs/`**
  - `HubFigure`: the shared figure. Caption, credit, intrinsic `width`/`height`, `role="img"` with `<title>` and `<desc>`, and an
    optional data table in `<details>`. It sets `data-moment` and `data-media-id`.
  - `HubMoment` wraps an existing visual (StatTiles, BarChart, ScatterPlot, OrbitSystem, LongHorizonTimeline) as a moment.
  - `HubLead`: a two-moment lead band.
  - `FilterIndex`: a no-script radio filter.
  - `HubEcosystem`: the ecosystem pointer, inside `data-context="ecosystem"`.
  - `CountMatrix`, `DotStrip`, `DeskConstellation`, `HorizonCompare` and `QuestionMap`.
  - Pure helpers: `geometry.ts`, `filter.ts`, `moments.ts` (the inventory) and `stats.ts` (register ids per hub).
- **Library, `src/components/library/`:** `ShelfDiagram` (one spine per document, numbered and linked) and `DocAnatomy` (the four parts
  every document shares).
- **Tools, `src/components/tools/`:**
  - `ToolMap` (the tools on the launch arc).
  - `ToolCard` with `ToolGlyph`.
  - `ToolSchematic`, an HTML flow of inputs, working and results, with the data in `schematics.ts`.
- **Layouts:** `FamilyHubPage` gained a `lead` slot (after the panel), which industries, compare and journey use.

## How to add a hub media moment

1. Pick the drawing:
   - A sourced chart or figure row from `components/visuals` goes inside `<HubMoment id="hub-<route>-<what>" kind="chart|stats|scene|timeline">`.
   - A new authored drawing goes inside `<HubFigure id=... kind=... width height title caption credit alt table>` with SVG children. Use
     `drawing="html"` for an HTML drawing.
2. Use register ids only (`STATS['ST-xx']` or `figures.ts`), and credit the source in `credit`. Give any data a `table`.
3. Add the id to the route's `moments` in `HUB_MOMENTS` (in page order) and to `tests/e2e/wave8/wp-24/hubs-media.spec.ts`. If it uses new
   register ids, add them to `HUB_STATS`/`HUB_FIGURES` and regenerate the ledger.
4. Keep the first two moments of a route in the first viewport or the first section after it, and use a heading level that follows the
   page outline (`headingLevel`).

## Known limitations and decisions

- Team Composer's "seats" wording is pinned by `tests/unit/wp-76/surfaces.ts`, and the FAQ description "what a seat is" is pinned by
  `tests/unit/wp-78/faq-page.test.ts`. Both are left as they are; WP-24 copy says "people per role".
- No JS on /insights/ (budget kept), and the industries orbit is static (no scene island).
- Founders imports sit below the copy constants so the RELEASE.md CR-17 line references (line 44) stay valid.
- `LongHorizonTimeline` (components/visuals, outside the write set) once missed its `positions.css` import, and /journey/ carried it
  for a while. The component now imports the sheet itself (wp/36-timeline-css, pinned by tests/unit/wp-36/positions-import.test.ts), so
  the page import was dropped once that fix reached demo.
- The ToolMap legend names its stations as text: the tool cards below it carry the one link to each tool, as the wave 7 tools hub
  contract expects (one link per tool name in main).
- The FAQ figures sit right after the question map, ahead of the question sets, so both FAQ moments open the page.
- On phones the CountMatrix on /resources/ scrolls sideways inside its own focusable region (the page itself never does). ShelfDiagram's
  spine numbers are small at 390, but the numbered, linked list under it carries the same information.
