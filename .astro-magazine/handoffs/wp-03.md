- Pages: `src/pages/{pricing,apply,contact,tools}/...`; copy: `src/content/pages/{pricing,apply,contact,tools}/*.mdx`.

## Forms layer
- Logic: `src/scripts/forms.ts` (validate, buildPayload, checkBot, submitIntake with timeout/abort, buildMailto), `src/scripts/team-composer.ts`.
- Config: `src/data/forms.ts`. Mode is `disabled` unless `PUBLIC_WE_INTAKE_API_URL` (https) is set, or a mailbox is confirmed (`mailto`).
- Components: `src/components/forms/{FormFrame,ApplyForm,ContactForm,NewsletterForm,ErrorSummary,FormStatus,HoneypotField,AsideStyles}.astro`; island `src/components/islands/we-team-composer/TeamComposer.astro`.
- Controls: native validation, label for/id, aria-describedby errors, error summary with focus, aria-live status, double-submit guard, honeypot, 3 s minimum fill time, 15 s timeout, no CAPTCHA.
- Tests: `tests/unit/wp-03/*.test.ts` (35 tests, node --test).

## Endpoint contract (B-2)
Authoritative text: `docs/forms-contract.md`. In short: JSON POST, CORS allowlist (never `*`), Origin check, rate limit with 429, honeypot returns silent 200, 400/422 with `{ok:false,errors:{field:msg}}`, also accept form-encoded and answer 303 to the `redirect` field for the no-JS path. No cookies, no PII in logs. If the endpoint cannot take form-encoded posts, build with `PUBLIC_WE_INTAKE_REQUIRES_JS=1`.
