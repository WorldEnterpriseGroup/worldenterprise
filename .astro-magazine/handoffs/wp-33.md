# WP-33 handoff: the ecosystem directory (issue #82, wave 10)

## Shipped

- `/ecosystem/` (HubLayout, console hero): "Join the ecosystem." The hero panel is a pure-SVG constellation (`Constellation.astro`): a founder at the center, eight kinds of program in orbit. Below it: eight category cards, a "how to choose" table (what you need, where to look, why), the directory, a ten-year timeline (`Timeline.astro`, WE as the long-running thread, with a table twin), a stats band counted from the data (`Stats.astro`), the FAQ (FAQPage JSON-LD), a "still under review" note, and the call to action ("Start a readiness review", "Talk to WE").
- Eight category pages `/ecosystem/<category>/` (MarketingLayout, one dynamic file `src/pages/ecosystem/[category].astro`): accelerators, incubators, university, coworking, angels, sba, government, communities. Each lists its programs with offers, who it is for, format, place, stages, the program link (rel="noopener", marked external in text) and a source line, plus three questions to ask before joining and links to the other kinds.
- Directory filter: `<we-ecosystem-filter>` (`src/components/ecosystem/EcosystemFilter.astro`, `src/scripts/ecosystem-filter.ts`). The server renders the whole directory as grouped lists; the form lives in a `<template>` and is inserted only when JavaScript runs. Filters: kind, stage, built for, online option. A `role="status"` live region says how many programs match; empty groups hide. Without JavaScript the page is the full directory plus the category pages and `#group-<category>` anchors.
- Messaging: "Join them. WE works alongside, for the long run." and "Independent programs; no affiliation implied unless stated." appear on every ecosystem page. No price, no "free", WE never described as an accelerator, investor or fund (`W10-*` rules restated in the unit test). Ecosystem markup carries `data-context="ecosystem"` as well as the route context.
- Data (`src/data/ecosystem/`): `types.ts`, one file per category, `categories.ts`, `index.ts` (helpers), `copy.ts` (all page copy as constants, so a test scans every word), `timeline.ts`, `schema.ts`. 64 entries, each with an official URL, a source URL, the retrieval month `2026-10` and a verification note.
- Ledger: `.astro-magazine/sources/wp-33.json` (older shape, one record per entry, no `fetches` array so the wave 8 host checker does not apply).
- Tests: `tests/unit/wp-33/ecosystem-data.test.ts` (breadth, fields, uniqueness, claims rules over all data and copy, disclaimer, JSON-LD, ledger parity); `tests/e2e/wave8/wp-33/ecosystem.spec.ts` (axe, named drawings, external links, filter with live region, keyboard, no-JS, 320px, 1920 full width).

## Exceptions used

- The e2e spec sits in `tests/e2e/wave8/wp-33/` (the 1920 project, registered in the write set), because a spec at `tests/e2e/wp-33*.spec.ts` matches no Playwright project.

## Decisions

- JSON-LD uses a `DefinedTermSet` of `DefinedTerm` nodes (name, url, description) because `ItemList` is not in `ALLOWED_TYPES` (`src/lib/schema.ts`, `scripts/validate-jsonld.mjs`), both outside this write set. Adding `ItemList` to both lists would let `src/data/ecosystem/schema.ts` emit the more precise type.
- The shared visuals components throw on ecosystem words in props, so the constellation, timeline and stat bars are own components under `src/components/ecosystem/`.
- Stats are counts of the directory itself; no outside figure is quoted.
- No `/sbir-sttr/` link unless the route is live at build time (`isLiveOnDisk`); the government entry links to sbir.gov.

## Deferred, with reasons (not listed because not verified in October 2026)

- Encore (50 and over) founder programs: no current, active official page found (Blissen, AARP Work for Yourself@50+, PCC ENCORE Business Builders). The page says so under "Still under review".
- Black founder programs beyond BGV Foundation (Black Ambition: certificate error), Hello Alice (page blocked), MBDA business centers (site blocked), state economic development offices (none verified), EDA and USDA Rural Development (pages blocked).
- Not taking applications or unverifiable: MassChallenge (no programs open), AngelList (no founder product), Plug and Play (thin page), Keiretsu Forum (expired certificate), StartEngine (no connection), Republic (blocked), Unshackled Ventures (SSL error), IFW by Honeycomb (audience not stated), Bunker Labs (legacy), Iowa SBDC Rural Business Innovators (no details).
- Hosts that block automated fetch (wework.com, wefunder.com, news.stanford.edu, score.org) were confirmed by search and by the SBA page for SCORE; their entries link the official site.
- `ItemList` allowlist (see Decisions).
