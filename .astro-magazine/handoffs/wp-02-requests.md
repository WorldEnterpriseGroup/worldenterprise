# WP-02 change requests (for WP-15 unless a named owner is given)

1. **ServiceLayout: separate the SEO title from the h1 (WP-13).** `ServiceLayout` passes one `title` to both `<h1>` and `<title>`. Four of the seven official line names exceed 31 characters, which is the most a page title can hold with the " | World Enterprise Incubator" suffix inside 60. WP-02 therefore uses `shortTitle` for both ("Management and Operations", "Fundability and Readiness", "Professional Coordination", "Customer and Market Development") and prints the full agreement name in the eyebrow. Proposal: add an optional `heading` prop to `ServiceLayout` (used for the h1, falling back to `title`), then WP-15 switches `src/pages/services/[slug].astro` to `heading={data.title}`.
2. **Services schema: optional `artifacts` field (frozen `src/content.config.ts`).** The "What you receive" table is MDX body today. Proposal: `artifacts: z.array(z.strictObject({ name: z.string(), purpose: z.string() })).default([])` so the artifacts can be indexed and cross-linked to library templates. Not needed for release.
3. **HubLayout: hero slot (WP-13).** The services hub uses `HubLayout` with a split intro block (copy plus hex strip) as the first slot content, because `HubLayout` always renders the editorial `PageHeader`. Proposal: let `HubLayout` accept `hero="console"` that renders `HeroConsole` with the panel slot, and promote `src/components/services/HubIntro.astro` as the pattern.
4. **Promote `ServiceLinesStrip` (WP-13).** `src/components/services/ServiceLinesStrip.astro` wraps `HexAtlas` for the seven lines. WP-01 (home strip) can import it or WP-13 can promote it into `components/diagrams/`.
5. **Playbook titles come from a constant (WP-15).** `PLAYBOOKS` in `src/components/services/lines.ts` holds the five playbook titles and one-line descriptions so line pages can link them before WP-04 merges. Once the `playbooks` collection is populated, replace the constant with a lookup by slug.
6. **FAQ entries (WP-08).** Line pages carry 3 questions each in the MDX body (`FaqList`), and the hub carries 4. `faqRefs` is left empty because `src/data/faq.yaml` holds only a fixture. WP-08 may promote any of these to `faq.yaml` and then WP-15 can switch the hub to `faqRefs`. Questions worth promoting: "Do I have to take all seven lines?", "Does WE replace my lawyer or accountant?", "Does WE find investors for me?", "Does WE host and run my live product?".
7. **Image alt text (WP-12).** Slots `svc-a` to `svc-g` and `inset-services` are rendered with the slot's `alt`. While they hold placeholders the alt is empty, which is correct for decoration. When WP-12 fills them the alt text will appear automatically on the line pages and the hub.
