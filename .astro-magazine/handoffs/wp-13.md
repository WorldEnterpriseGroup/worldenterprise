# WP-13 handoff: design system steward and motion

## What shipped
- Cascade-layer order is now declared inline first in `src/layouts/BaseLayout.astro`. Any component sheet that opens a layer before the global sheet loads would otherwise demote the layer order (this caused the styleguide axe failure). Every `is:global` block I added repeats the full order statement. Rule for all WPs: if a component ships global CSS, open it with `@layer reset, tokens, base, layout, components, utilities, pages, print;`. A unit test guards this.
- 390px overflow: `.page` is a single `minmax(0, 1fr)` column, grid and flex children get `min-inline-size: 0`, hero/form/CTA columns use `minmax(0, ...)`, and `.page` plus `main` use `overflow-x: clip` as a safety net.
- Mega menu: chevrons, accent top border, column headings, featured aside, hover grace period and focusout close in `src/scripts/nav.ts`. Mobile drawer polish and `--scrim` token.
- Motion (`motion.css`): scroll reveal and stagger, hero drift, card hover, view-transition rules. All gated behind `@supports` and reduced-motion no-preference.
- Print layer rewritten; forced-colors rules in `base.css`.
- New components: `diagrams/` (AltitudeDiagram, SeatDiagram, ServiceLinesStrip, HexAtlasArt, ConsolePanel, RoadmapPanel, RiskRegisterPanel, SeatRosterPanel, WeeklyReviewPanel, hex.ts), `motion/Reveal.astro`.
- Layout additions: `ServiceLayout` `heading` prop; `HubLayout` `hero="console"` with a `panel` slot; `HeroAtlas` `strip`; `HeroEditorial` `inset`; `Faq` `id`.
- `scripts/audit-tokens.mjs` (raw colours, stray `!important`, magic spacing): 0 violations. 90 unit tests in `tests/unit/wp-13/`.

## QA findings closed here
- Utility bar overflow at 390 px: root cause was the unbounded auto grid column on `.page` (fixed above) plus a non-wrapping utility list; the list now wraps.
- `button.btn--primary` contrast: the colours pair at over 9:1, so the failure was the layer-order demotion (reset `color: inherit` beating components when a component sheet opened a layer first). Fixed by the inline layer statement in `BaseLayout`.
- Mega panel headings (WP-09 W13-2): now `<p class="mega-panel__heading">` labelling each `section` via `aria-labelledby`, so no h2 precedes the page h1.
- Footer links to unbuilt routes: data issue for WP-15, untouched.
