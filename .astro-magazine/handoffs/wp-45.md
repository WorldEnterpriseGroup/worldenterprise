## How it works

- Tints are light washes only; there are no dark sections and no color mode. Tinted bands carry `section--soft` as well, so every existing soft-band rule still holds; two tinted bands keep both paddings.
- All new motion is CSS only, inside `prefers-reduced-motion: no-preference` and `@supports (animation-timeline: view())`. The default style is the finished picture. Offsets are vertical only (the layout and overflow specs forbid horizontal ones). No text opacity is animated, so axe never sees a mid-animation contrast.
- The rails: `StageRail` (Dream, Build, Grow as three stops; the line from the current stop fills as it scrolls in; `aria-current="step"` on the current link) is drawn on stage pages only, between the hero and the body. The program diagram gets a line under its three steps that draws left to right, and the home diagram's connector draws in two steps.
- The statement hero is the compact hero with `data-variant="statement"`, not a new `data-hero` value, because `tests/e2e/folds.spec.ts` (`HERO_MODES`) and `tests/unit/wp-17/heroes.test.ts` are outside the write set and pin `data-hero` to editorial or compact for MarketingLayout. It applies to `/founders/`, `/investors/` and `/network/operators/` (marketing pages with no photo or art). From 52rem up the h1 is one half-step larger; on a phone it keeps the h1 size so the primary action stays inside the first viewport above the Apply bar.
- New variants keep their CSS in scoped `<style>` blocks, so they ship only on pages that use them. They lay themselves out from container width (`@container`), not the viewport. Each has a forced-colors block.
