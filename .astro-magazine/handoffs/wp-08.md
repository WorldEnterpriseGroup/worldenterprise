- `/newsletter/`: `src/pages/newsletter/[...slug].astro`, `getStaticPaths` returns `[]` unless `forms.newsletter.mode === 'endpoint'`. In CI and preview (no endpoint) it is not emitted and the ledger row is `launch:false`: 89 routes. See request R-1.
- `/search/` (noindex via ledger): `<we-search>`.

## Islands

- `<we-copy>` (`src/scripts/copy.ts`, host `components/islands/we-copy/WeCopy.astro`): renders nothing until upgraded and nothing at all without `navigator.clipboard` (print button only if `print`). Copies the prefetched `.md`, falls back to the rendered text. No-JS: the Markdown download link and the document itself.
- `<we-search>` (`src/scripts/search.ts`, host `components/islands/we-search/WeSearch.astro`, pure helpers in `query.ts`): loads Pagefind at runtime from `asset('/pagefind/pagefind.js')` (the index exists only after postbuild), `?q=` read on load and kept in sync with `history.replaceState`, debounced input, race-safe, 10 results per page with "Show more", prefixes the preview base to result URLs, excerpts rendered as text plus `<mark>` only. The form is `hidden` until the index loads; the fallback block (site map, resources, templates, glossary, FAQ links, each only if live) shows without JS and on index failure.
