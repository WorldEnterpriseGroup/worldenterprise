# WP-00 handoff: Foundation

Status: G0 reached on `demo`. Wave 1 may start. Verified in CI only (verify:static, e2e:smoke with axe, pages; check:ownership on wp/* branches).

## How to work

- Branch `wp/NN`; `scripts/check-ownership.mjs` fails any path outside your write set or inside a frozen path.
- All internal links use `href()`, `asset()`, `absoluteUrl()` from `src/lib/url.ts`. Nav only shows launched routes that exist (`getRouteState()`).
- Claims: cite only ids from `src/data/claims.ts` via `claimsUsed`. Excluded claims cannot be enabled. `claims-denylist.json` is scanned against `dist`.
- Photos: import by slot id from `src/assets/photo/index.ts` (`getPhoto`). Never reference a filename. WP-12 fills slots.
- Drafts: `draft: true` is noindex and fails `PUBLIC_RELEASE` builds. Fixtures live in `src/content/<collection>/_fixtures/`, fixture routes are excluded from the sitemap by the `/fixture-` filter; WP-15 removes them.
- Styleguide: `/styleguide/` is built when `PUBLIC_STYLEGUIDE=1` (CI and preview only) and shows every component, the contrast table and layouts.
- `PUBLIC_NAV_FIXTURE=1` (verify build only) renders the full nav for browser tests; never set it for preview or production.
