## Decisions worth knowing

- `/llms.txt` and `/llms-full.txt` are built from data: `src/data/site.ts`, `src/data/packages.ts`, the service entries and the Markdown twins. The add-on paragraph is not typed into any `src` file. It is read from the answer on the facts page (`addOnStatementFrom`), so the verbatim disclaimer lives in one place, and wp-18 and wp-30 source-level rules stay satisfied.
- `llms-full.txt` is capped at `LLMS_FULL_MAX_BYTES` (256 KiB). Over the cap the build throws `LlmsFullTooLargeError`; the unit test proves it with a lower cap.
- `/program/how-we-decide/` (WP-43) is listed in `llms.txt` only when the route exists (`howWeDecide` is `null` otherwise). No edit is needed when WP-43 merges.
- Twin routing: `src/pages/[...path].md.ts` maps to the pattern `/[...path].md`, which matches no row of the route ledger (a unit test proves it), so the route ledger is unchanged.
- Twin coverage: 28 twins are emitted (3 about, 7 services, 5 playbooks, 4 research briefs, 4 insights, 3 legal, the FAQ and the glossary). 14 insights are skipped because they use `DataTable`, `CellTrail` or `NoFundingDisclaimer` in the body; stripping `NoFundingDisclaimer` would duplicate hand-typed text, so they are deferred rather than approximated. Pages whose text comes from `.astro` components (pricing, who it is for, apply, program pages, investors, network, about index, guides) have no twin yet. A page with no twin emits no alternate link, and `llms.txt` links to the page instead.
- Offers: `Offer` stays a forbidden `@type` everywhere except inside the organisation's `OfferCatalog` (path-scoped in `validate-jsonld.mjs`). The catalog lists the four packages by name with `itemOffered` Service nodes, no price, no seat count, no digit. `knowsAbout` is the seven service lines. `sameAs` is still the GitHub organisation only. Research briefs carry `citation` as `CreativeWork` nodes with a publisher. The facts page is an `AboutPage` with `about` pointing at the organisation `@id`.
- WebApplication contract (for WP-49): `validate-jsonld.mjs` accepts a `WebApplication` node with `@id`, `name` and `url`, and refuses one with `offers` or a price. This lives in the validator and its test, not in `docs/wave7-contracts.md`.
- Citation author is "World Enterprise Editorial" (`CITATION_AUTHOR` in `cite.ts`). It names no person. Change it in one place if the owner prefers another byline.
- `CiteThis` uses the existing `<we-copy>` island with no `source` attribute, so the island copies the text of its target. No new script, no new request.
