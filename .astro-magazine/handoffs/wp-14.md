## Reading the artifacts

- `reports/*.json`: each audit writes its findings (`level`, `where`, `message`). `reports/lighthouse/summary.json` has one row per route.
- `test-results/screenshots/<project>/<route>.jpg`: 1440 and 390 full-page JPEG per route (quality 55 to keep artifacts small). The `playwright-report/` HTML report has traces for failures.
- Overflow failures name the elements that stick out (`... by div.site-top right=640`).

## Blocking policy

`verify:static` and `check:ownership` always block. Every qa job is `allow_failure: true` on wp/* and demo until `QA_STRICT=1` (CI/CD variable) so heavy suites cannot hold a WP merge. On `gh-pages` and on any branch ending in `negatives` every qa job is strict. `mirror` needs all of them, so production cannot reach GitHub with a red qa job. `RELEASE_ALLOW` defaults to `^launch:true route does not exist,^draft content remains,^launched form route`; it is empty on gh-pages.

Pending routes: a launched ledger route that is not built yet is skipped in e2e (listed as skipped, with its owner) and is a warning in the audits. `--strict` (and gh-pages, via pages.yml) turns them into errors.

## Deviations

- `package.json` and the lockfile are frozen by `ownership.json`, so no npm scripts were added; jobs call the scripts directly. `linkinator` stays an unused devDependency: `scripts/audit-links.mjs` is an offline checker with ledger-aware pending and orphan logic.
- Audit scripts are plain `.mjs` that read `reports/ledger.json` (exported by `scripts/lib/export-ledger.mjs` through Node 24 type stripping) because the Playwright image's Node version is not guaranteed to strip types.
- The skill's audit scripts (`audit-editorial-corpus`, `audit-route-media`, `audit-seo-collisions`, `audit-publication-release`) live in a home directory CI cannot reach; they are not run. Their coverage is partly provided by `audit:ledger`, `audit:images`, `audit-seo.mjs` and `verify:release`.
- `e2e/smoke.spec.ts` is no longer run (`testDir` is `tests/e2e`); its cases are ported. WP-15 should remove the `e2e/` directory.
- Lighthouse runs through Playwright's Chromium with a debug port; the served page has its canonical origin rewritten to the local one so the SEO category can pass.
