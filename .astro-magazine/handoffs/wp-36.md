# WP-36 handoff: seamless HTML5 scenes (#85)

Branch `wp/36-html5`. three 0.186.1 (latest stable, no package change). Scenes use `WebGPURenderer` from `three/webgpu` with TSL node materials; WebGPU on a hardware adapter, WebGL2 (forceWebGL) otherwise, poster last.

## Support and fallback matrix
| Feature | Used for | Fallback |
|---|---|---|
| WebGPU | scene renderer on hardware adapters | WebGL2 via the same renderer, then poster |
| TSL node materials | galaxy, nebula, accretion, world globes | n/a (same renderer both backends) |
| Cross-document View Transitions | header (`site-top`), page title, `hero-media` | plain navigation |
| Scroll-driven animations (`view()`, `@property --depth`) | edge feather depth, reveals | static feather |
| `@starting-style` | canvas crossfade, toggle entry | instant swap |
| Popover + anchor positioning | Scene `legend` slot | popover without anchoring |
| `<dialog closedby>` + `commandfor` | Scene `detail` slot | `showModal()` script fallback |
| `@property` | poster `--sheen` single sweep, `--depth` | static poster |
| Speculation rules | already present in `SpeculationRules.astro` (hash in CSP) | none needed |
| OffscreenCanvas worker | skipped: Vite worker output and CSP make a clean same-origin module worker unproven | main thread |

## Budgets
Scene code is a lazy chunk (about 245 KB gzip with the WebGPU build), loaded only after the gate (desktop, fine pointer, >=64rem, motion allowed, >=4 cores, hardware GL/GPU). The per-route eager JS budget (10,240 B gzip) is unaffected: only the stub ships. Posters are 3840-wide AVIF masters (19 to 200 KB), candidates 640 to 3840.
