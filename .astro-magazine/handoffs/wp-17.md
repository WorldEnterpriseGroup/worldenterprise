# WP-17 handoff: heroes, page openers and typographic rhythm (Wave 4)

Branch `wp/17`, issue #24. Every check below ran in CI; locally only `npm ci`, `astro sync`, `astro check`, `tsc` over the specs, `node --test` and the audit scripts ran. No build and no Playwright run happened on this machine.

## What changed

| Area | Change |
|---|---|
| Type scale | One modular scale in `src/styles/tokens.css`: ratio 1.2 at 360 px growing to 1.32 at 1440 px, as `--fs-xs` to `--fs-4xl`. Heading roles `--fs-h1` (3xl), `--fs-h2` (xl), `--fs-h3` (lg), `--fs-h4` (base). Body is 17 px on a phone and 19 px at 1440 |
| Rhythm | Fluid `clamp()` tokens `--space-heading`, `--space-flow`, `--space-group`, `--space-block`, `--space-section`, `--space-hero`. `--section-y` now aliases `--space-section`. Same-tone bands share one gap; `.stack` and prose headings take their space-before from the tokens instead of a fixed 16 to 104 px |
| Hero system | `src/components/hero/`: `HeroEditorial`, `HeroConsole`, `HeroArticle`, `HeroCompact`, the shared `HeroActions` and `HeroArt`, `PageHero` (editorial when a page names a `photo` or `art`, compact otherwise), `ctas.ts` (Apply, Talk to WE, Compose your team, `jumpTo`). Styles in `src/styles/hero.css` (components layer plus a small utilities block for `.lead` and `.rule`) |
| Layouts | All 15 layouts open with a hero; the `.page-header` markup and rules are gone. `layout/PageHeader.astro` stays as a thin wrapper over `HeroCompact` because the WP-13 component inventory lists it. See the table below |
| Primary actions | Every hub, stage, service line and playbook carries one above the fold. Single pages: about, press, founders, investors, operators, apply, contact, pricing, team composer, 404. Templates put the Markdown download in the hero |
| Photo slot | `photo` prop on `PageHero`, `HeroEditorial` and the layouts. The vector art stays as the fallback. `src/assets/photo/**` was not touched |
| FAQ | `/faq/` renders each group through `FaqList` (group-scoped `details name`, every answer id kept, FAQ JSON-LD still built from the full list). `components/reference/FaqGroups.astro` is deleted. `FaqList` items take an optional `id` |
| Console heroes | `/services/` (service lines A to G in the panel) and `/network/` (founders, operator roles, investors) |
| Services `artifacts` | Optional `artifacts: [{ name, purpose }]` in `src/content.config.ts`; `ServiceLayout` renders it as "What you receive" before the body. No entry uses it yet, see Remaining |
| Tests | `tests/unit/wp-17/` (type scale, rhythm, heroes, layouts, FAQ, artifacts); `tests/e2e/folds.spec.ts` (one h1, one hero of the right mode, primary action inside the first viewport at 1440 and 390 with the fixed mobile Apply bar subtracted) |
| Styleguide | Hero section shows the five modes with the new props; Type section shows the scale, the heading roles and the rhythm tokens |

## For the photography pass (WP-12b)

- Pass `photo` to a layout or to `PageHero`; the editorial hero renders the image inside `.hero__frame` (16 by 9 on a phone, 4 by 3 beside the copy) with `position: absolute` fill, so any width and height pair keeps the reserved box.
- Keep the `<img src width height alt fetchpriority="high" decoding="async">` shape in `HeroEditorial`. Only one image per page may carry `fetchpriority="high"`; the unit test `heroes.test.ts` lists the only files that may name it.
- Reading-column measures (`prose`, `rail`) never show a media frame, so a photo on a prose page has no effect by design.
